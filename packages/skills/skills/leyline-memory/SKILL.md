# Leyline Memory

Recall focused memory before non-trivial repository work, debugging, reviews,
or continuity-sensitive answers. In monorepos, include the files in focus so
package-local knowledge ranks correctly.

Apply only relevant memories and mark only the ones actually used as useful.
Remember verified, durable decisions, preferences, root causes, and repository
rules with the relevant files attached. Never store secrets, raw transcripts,
or guesses as durable facts.
